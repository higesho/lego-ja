# LEGO シリーズ 日本語化プロジェクト

LEGO のゲームを日本語で遊べるようにする、非公式のファンメイド日本語化プロジェクトです。
Steam で販売されている PC 版を対象にしています。
開発元・販売元とは関係ありません。

- サイト（作品の紹介・入れ方）: https://higesho.github.io/lego-ja/
- ダウンロード: [リリース](https://github.com/higesho/lego-ja/releases)

## 作品一覧

| 作品 | 状態 | ダウンロード |
|---|---|---|
| LEGO ロード・オブ・ザ・リング（LEGO The Lord of the Rings） | 公開中（v1.1） | [LEGOLOTR_JP.zip](https://github.com/higesho/lego-ja/releases/tag/lotr-v1.1) |

入れ方と外し方は、サイトの各作品のページをご覧ください。
どのパッチも、ゲームのファイルを書き換えません。配布物には原作のプログラムやデータは入っていません。
